# 一页式比赛项目方案

## 项目名称

GlobalPool AI：基于 AI 预测的跨境电商海外仓智能补货与分仓系统

## 核心口号

库存池供货全球，让每一件库存都去最需要它的海外仓。

## 参赛定位

本项目面向跨境电商、智慧物流、供应链数字化、人工智能应用与创新创业类比赛。它不做 OMS/WMS/ERP 后台大杂烩，而是解决一个可被量化验证的问题：相比传统按国家/仓库各自备货，智能库存池方案能否降低缺货、降低库存积压、提升履约时效。

按 4-6 人团队、4-8 周开发周期设计，核心交付物是原型系统、算法说明、数据仿真、比赛 PPT/论文材料。

## 痛点

| 痛点 | 业务后果 |
| --- | --- |
| 海外仓库存割裂 | 总库存充足时仍发生区域缺货 |
| 补货依赖经验 | 提前期长，错过窗口后缺货损失扩大 |
| 固定比例分仓 | 热销区域补不够，滞销区域堆库存 |
| 缺少可解释建议 | 业务人员难以信任自动化决策 |

## 解决方案

系统以“全球库存池”为供给核心，将中国供应中心、在途库存和可调拨库存统一管理。AI 模块按 SKU-海外仓维度预测 P50/P80/P95 需求，策略模块计算安全库存、补货点和目标库存，分仓模块再依据缺货风险、服务等级、利润贡献和尾程履约能力，把库存池库存动态分配到全球海外仓。最后，仿真模块用 90 天滚动情景验证智能方案相对传统方案的改善。

## 创新点

- 从“单仓补货”升级为“全球库存池调度”。
- 从“经验分仓”升级为“预测 + 风险 + 利润 + 时效”的智能分仓。
- 从“黑箱建议”升级为“可解释补货原因和优先级”。
- 从“静态备货”升级为“滚动预测、滚动补货、滚动分配、滚动评估”。

## 技术方案

```text
数据中心 -> AI需求预测 -> 补货优化 -> 全球库存池分配 -> 履约仓选择 -> 仿真评估
```

三类决策层：

| 决策层 | 输出 |
| --- | --- |
| 需求预测 | 未来 7/14/30 天 SKU-仓维度 P50/P80/P95 需求 |
| 智能补货 | 补货点、目标库存、建议补货量、安全库存 |
| 智能分仓与履约 | 库存池分配量、跨仓调拨/履约仓选择、未满足缺口 |

当前原型已实现：

- 需求预测：LightGBM / XGBoost / RandomForest 机器学习集成，缺包时启用内置随机森林兜底，输出 P50/P80/P95。
- 补货策略：安全库存、补货点、目标库存。
- 智能分仓：优先级评分和库存池约束分配。
- 仿真评估：传统独立备货 vs 智能库存池方案。
- 决策输出：JSON + Markdown + HTML 驾驶舱。

## 商业价值

- 降低缺货率：优先保障高风险、高价值区域仓。
- 提升库存周转：避免盲目铺货和低效库存积压。
- 降低计划成本：减少人工汇总销量、库存和在途数据的时间。
- 提升履约体验：更稳定地满足本地发货时效。

## 演示方式

运行：

```bash
PYTHONPATH=src python -m overseas_inventory.demo
```

系统会输出补货建议、库存池分配计划、90 天仿真对比和 HTML 驾驶舱，可现场展示 `output/dashboard.html`。

## 发展路线

第一阶段完成原型验证；第二阶段接入真实 OMS/WMS/ERP 数据；第三阶段升级机器学习预测模型；第四阶段建设 Web 控制台和自动审批工作流。
