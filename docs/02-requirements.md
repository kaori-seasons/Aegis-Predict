# 需求说明

## 用户角色

| 角色 | 关注点 | 系统能力 |
| --- | --- | --- |
| 供应链计划员 | 哪些 SKU 需要补货，补多少，先补哪个仓 | 补货建议、缺货预警、目标库存 |
| 海外仓运营 | 仓库是否承压，到仓节奏是否合理 | 仓容与处理能力约束、到仓计划 |
| 采购与供应计划 | 全球库存池是否足够，缺口是否需要采购 | 库存池水位、未满足缺口 |
| 经营负责人 | 库存资金、利润、服务体验如何平衡 | 优先级评分、利润与服务权衡 |
| 学生项目成员 | 数据从哪里来，字段如何整理 | 数据契约、模型配置、任务调度 |

## 功能需求

### 1. 数据整合

- 维护 SKU 主数据：品类、包装数、单位利润、服务等级。
- 维护海外仓主数据：区域、国家、处理能力、尾程履约评分。
- 维护运输链路：库存池到海外仓的提前期和单位成本。
- 汇总库存数据：现货、在途、已分配、可售库存。
- 汇总需求历史：SKU-海外仓维度的每日销量。

### 2. 需求预测

- 支持按 SKU-仓维度生成预测。
- 输出日均预测、预测周期需求、波动率和置信度。
- 允许学生在上传数据中加入促销、价格、广告、季节、平台活动等外部特征。
- 对预测低置信度的 SKU 标记风险，降低自动执行等级。

### 3. 智能补货

- 按运输提前期和需求波动计算安全库存。
- 按服务等级设置不同安全库存系数。
- 计算库存位置：现货 + 在途 - 已分配。
- 输出补货点、目标库存、建议补货量和紧急度。
- 按包装数或箱规对补货量取整。

### 4. 库存池分仓

- 从全球库存池扣除保留量，得到可分配库存。
- 当库存池不足时，按优先级分配，不平均摊薄关键需求。
- 分配优先级综合考虑缺货风险、需求规模、服务等级、利润贡献和尾程能力。
- 输出每个仓的分配数量、未满足缺口、预计到仓天数和决策说明。

### 5. 决策输出

- 生成结构化 JSON 结果，便于下载复用和答辩展示。
- 生成 Markdown 决策表，便于人工查看、汇报和归档。
- 保留每次计划的输入数据版本、预测周期和算法参数。

## 非功能需求

| 类别 | 要求 |
| --- | --- |
| 可解释性 | 每条建议需要说明触发原因和关键指标 |
| 可配置性 | 服务等级、安全库存系数、预测周期、箱规可配置 |
| 可扩展性 | 预测模型、分配策略、约束优化模块可替换 |
| 稳定性 | 数据缺失、库存不足、无运输链路时应给出明确状态 |
| 审计性 | 每轮补货计划可保存输入、输出和参数 |
| 人机协同 | 系统给建议，关键补货动作可由计划员审批 |

## 当前版本不包含

- 企业平台接口对接。
- WMS 出入库单自动下发。
- 财务付款、采购合同和报关单证处理。
- 完整机器学习训练流水线。
- 多角色权限体系和企业级审计流。
