# 项目立项说明

## 项目名称

面向 3C 配件跨境电商的海外仓智能补货与分仓系统设计 - 基于 AI 需求预测与全球库存池协同优化

## 背景

本项目聚焦一家主营 3C 配件的中国跨境电商卖家。商品包括 USB-C 快充线、手机支架、蓝牙耳机保护壳、平板保护壳、USB-C 拓展坞和笔记本支架。卖家从深圳中心仓向美国洛杉矶仓、德国法兰克福仓、英国伯明翰仓和澳洲悉尼仓补货。这个场景 SKU 多、体积小、促销波动明显、物流方式可切换，适合比赛演示。

跨境电商企业在多国家、多平台、多海外仓运营时，常见问题不是“总库存不够”，而是“库存放错地方”。某些区域仓库缺货导致配送时效下降、广告转化损失和平台评分下降，另一些仓库却形成滞销库存，占用资金和仓容。传统补货方式依赖人工经验、固定安全库存和单仓独立计划，难以应对需求波动、促销冲击、国际运输提前期长、区域销售结构快速变化等问题。

本项目将海外仓库存从“各仓自有库存”升级为“全球共享库存池”。系统先预测每个 3C 配件 SKU 在各海外仓的未来需求，再计算补货点、目标库存和缺口，最后从统一库存池向全球仓网动态分配货源，使库存以服务全球订单为目标，而不是被静态锁定在单个仓库。

## 核心问题

- 需求预测滞后：补货决策主要依赖历史均值或人工判断，无法及时捕捉区域需求变化。
- 库存割裂：各海外仓库存独立管理，总库存充足时仍可能发生局部缺货。
- 分仓粗放：分仓常按固定比例或主观经验，缺少服务等级、利润、时效和风险的综合权衡。
- 提前期长：跨境运输链路长，一旦错过补货窗口，缺货损失会被放大。
- 决策不可解释：补货建议缺少原因说明，业务人员难以信任系统输出。

## 建设目标

| 目标 | 说明 |
| --- | --- |
| 预测驱动 | 建立 SKU-仓维度的需求预测，支持未来 30 天或可配置周期的销量判断 |
| 智能补货 | 基于提前期、安全库存、服务等级和库存位置生成补货建议 |
| 全球库存池 | 统一管理可分配库存、保留库存和各仓补货需求 |
| 动态分仓 | 根据缺货风险、服务等级、利润贡献和履约能力做库存分配 |
| 可解释决策 | 输出补货原因、优先级、分配数量和未满足缺口 |
| 可复现数据 | 使用 15 个具体 SKU、4 个海外仓、180 天模拟销量构成比赛样例 |

## 成功指标

- 缺货率下降：高优先级 SKU 的预计缺货风险降低。
- 周转效率提升：目标库存不再简单堆高，而是按需求和时效动态调整。
- 决策周期缩短：补货计划从人工汇总转为系统自动生成。
- 分仓准确性提升：库存向需求增长区域和高履约价值区域倾斜。
- 可追溯性增强：每条补货和分仓建议都能解释其计算依据。

## 项目边界

当前版本是系统设计与最小可运行比赛原型，不做企业系统对接。样例数据用于验证核心逻辑，后续可替换为学生整理的真实订单、广告、促销、价格、库存和仓网资料。
